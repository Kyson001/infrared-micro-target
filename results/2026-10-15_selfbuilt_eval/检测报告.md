# 四数据集模型检测自建数据集（2026-10-15）

## 一句话结论

用四套公开红外数据训出的模型 `models/all4_seg_4datasets/best.pt` 去检测自建数据集
`infarad micro-target`（490×600、单类 UVA、3315 训练 + 1428 验证、共 16,776 个目标框），
**在 conf≥0.25、IoU≥0.5 下 TP = 0，AP50 = 0**；降低置信度、切换输入分辨率、做对比度增强都无法挽回。
这是一个显著的**跨域失败**，不是阈值或预处理问题——同一批图片用自建数据训练出的模型可以正常检出（见第 4 节对照实验）。

## 1. 检测与评估设置

| 项 | 值 |
| --- | --- |
| 权重 | `models/all4_seg_4datasets/best.pt`（YOLO26n-seg，单类 `target`） |
| 数据 | `infarad micro-target/target data`：train 3315 张 / 11,725 框，val 1428 张 / 5,051 框 |
| 推理 | imgsz=1024、batch=8、FP32、`rect=False`、`max_det=300`，保留 conf≥0.05 全部候选 |
| 指标 | 贪心一对一匹配（按置信度降序）、IoU≥0.5；AP50 与 AP50-95 用全点插值；工作点 conf≥0.25 |

## 2. 主结果

| 划分 | 图像 | 真值目标 | TP | FP | FN | P | R | AP50 | AP50-95 | 每图预测框 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| train | 3315 | 11725 | 0 | 329 | 11725 | 0.000 | 0.000 | 0.000 | 0.000 | 0.10 |
| val | 1428 | 5051 | 0 | 138 | 5051 | 0.000 | 0.000 | 0.000 | 0.000 | 0.10 |

全数据集 4,743 张图上，conf≥0.25 的预测框只有 467 个（0.10 个/图）；即使把全部候选（conf≥0.05，1,349 个）算上，也没有一个落在真值框上（IoU≥0.5）。

## 3. 失败原因：目标外观与对比度完全不在模型的训练分布内

**自建数据的目标是"弥散、低对比的模糊斑块"**：

| 指标 | 自建数据集（infarad） | 公开训练集（例：NUAA-SIRST） |
| --- | --- | --- |
| 灰度动态范围 | 67–121（跨度 55） | 0–255（跨度 255） |
| 灰度标准差 | 11.9 | 63.0 |
| 目标形态 | 弥散斑块，局部均值 103 vs 全图 91（差约 12 灰阶） | 紧凑亮斑，与背景差常达数十灰阶 |
| 目标框尺寸 | 中位 15×15 px / 490×600 图 | 2–40 px / 128–512 图 |

四套公开数据（尤其 MDFA、NUDT-SIRST）的学习目标都是"**高局部对比度的紧凑亮核**"，
而在自建数据里这种结构**根本不存在**，因此模型的质量/置信度输出普遍低于 0.01，整幅图不产生任何目标响应。

## 4. 排查过程（排除技术性原因）

| 排查项 | 结果 | 结论 |
| --- | --- | --- |
| 模型文件是否正常 | 同一权重在公开测试图上正常检出（conf 0.42–0.63） | 权重无损 |
| 数据读取是否正常 | 图像 uint8、600×490、可正常解码；同流程自建模型可检出 | 数据与流程正常 |
| 降低置信度 | conf 0.25 / 0.05 / 0.01 → 20 张对照图均 0 个框 | 不是阈值问题 |
| 换输入分辨率 | imgsz 640 / 1024 / 1536 → 均 0 个框 | 不是尺度/letterbox 问题 |
| 对比度增强 | 1–99 百分位拉伸、CLAHE → 仍 0 个框 | 全图统计变换无法造出模型所需的"尖锐亮核" |
| **对照实验：自建模型** | 用自建数据训练的 UVA 检测模型，同 20 张图 **20/20 检出** | 确认是**域差异**，不是数据或代码问题 |

这一结果与 2026-09-19 的相反方向实验互为镜像：当时用自建数据训练的模型去测 SIRST，
严格框指标同样接近 0。**两个方向都失败，说明"自建 UVA 域"与"公开 IRSTD 域"之间存在系统性的分布差异。**

## 5. 结论与改进方向

1. **不要把公开红外数据集直接当作自建数据的替代或预训练终点**：合并四套公开数据训练，并不会让模型自动适配自建的弥散低对比目标。
2. **必须用自建数据微调**（或至少把自建数据加入训练集）：可用的初始化是 `yolo26n-seg.pt` 或本模型，在自建数据上微调几十轮即可恢复检出能力。
3. 若希望公开数据真正有用，应先做**域对齐**：把自建图做局部对比度归一化（如高帽滤波/局部标准化）后再训练，或在训练时加入"低对比弥散目标"的合成样本。
4. 评估时请同时报告**中心命中率**（本次可复算），避免只看 IoU≥0.5 的框指标而掩盖"是否看到目标"。
